# MERN Real-time Chat Application

This is a real-time chat application built using the MERN stack with Pusher for instant messaging and no database dependency issues.

- **Frontend (Live Chat App):** [https://internship-assignment-no-4-5tdr.vercel.app/](https://internship-assignment-no-4-5tdr.vercel.app/) (or your working preview link: [https://internship-assignment-no-4-5tdr-l3x14pc2j-sadaf-iqbals-projects.vercel.app/](https://internship-assignment-no-4-5tdr-l3x14pc2j-sadaf-iqbals-projects.vercel.app/))
- **Backend API Status:** [https://internship-assignment-no-4.vercel.app/](https://internship-assignment-no-4.vercel.app/)

## 🚀 Features
- ⚡ **Instant Real-Time Messaging** using Pusher Channels.
- 🎨 **Premium UI/UX** with Glassmorphism and Animated Gradient glow.
- 🔒 **Room-based Chatting** (join specific rooms, isolated conversations).
- 📱 **Mobile Responsive** Design.
- ☁️ **Fully Serverless Backend** deployed on Vercel.

## 🛠 Tech Stack
- React.js + Vite (Client)
- Express.js + Node.js (Server)
- Pusher (WebSockets/Real-time)
- Tailwind CSS / Vanilla CSS (Styling)
